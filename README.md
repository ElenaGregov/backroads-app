
# Backroads — Travel Agency Landing Page

**React-based Single Page Application (SPA)**  
A responsive travel agency landing page with smooth navigation, services showcase, and tours section.

[Live Demo](https://backroads-app.netlify.app) *(if deployed)*

---

## Overview

> **Early learning project** from Jonas Schmedtmann's React course (Udemy)  
> **My focus:** converting static HTML/CSS into a dynamic React SPA

This was my **first React project** — built to practice:
- Component structure
- Props & state
- React Router (basic)
- Responsive layout with CSS

---

## Features

- Smooth scroll navigation
- Reusable components (`Navbar`, `Hero`, `Services`, `Tours`)
- Mobile-friendly hamburger menu
- Static data in JS objects
